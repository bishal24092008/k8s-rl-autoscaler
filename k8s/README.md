# Intelligent K8s Autoscaler

A modern DevOps project that simulates Kubernetes autoscaling behavior using a Flask backend and an interactive monitoring dashboard.

---

## 🚀 Features

- Live CPU usage monitoring
- Dynamic pod autoscaling simulation
- Response time tracking
- Workload status monitoring
- Active requests dashboard
- Kubernetes Deployment configuration
- Horizontal Pod Autoscaler (HPA)
- Flask backend APIs
- Modern responsive frontend UI

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask
- Flask-CORS

### DevOps
- Kubernetes
- HPA
- YAML Configurations
